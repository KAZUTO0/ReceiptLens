# 5-minute quickstart index (not an end-to-end training time estimate)

**Download ZIP → extract once → open notebook in Colab → set T4 → upload same ZIP in Step 2 → run all steps from top.**

The main notebook is `notebooks/ReceiptLens_Colab_Runbook.ipynb`.

## Checkpoints in notebook

| Step | Success condition |
|---|---|
| 1 | GPU appears |
| 2 | Python source folder found |
| 3 | Dependencies installed |
| 4 | Unit tests pass |
| 5–6 | Train / validation / test arrays loaded |
| 7–8 | Gemma predicts on one image |
| 9–10 | Baseline accuracy recorded |
| 11–14 | LoRA fitted, adapter saved |
| 15–16 | Comparison CSV and accuracy chart saved |
| 17 | Gradio demo launches |
| 18 | Results ZIP downloaded |

If `ReceiptLens_Colab_Runbook.ipynb` is opened without the ZIP, upload the ZIP at Step 2. The event's official notebook is linked in the README for dependency troubleshooting.
